PASS if the page is organised by a formal idea taken from this company's own facts (142 stops a day, a re-plan every 90 seconds, 31 depots, the plan board as the whole working day) and that idea is visible beyond the first screen: for example the real cadence or count sets the composition, the working interface is the page, or a true figure is set at commanding scale with everything else subordinate. Missing proof (customer quotes, logos) is absent or a clearly labelled slot. The narrow-screen layout is designed, with its own rules in the CSS, not only a stacked column.
FAIL if the page is the default for this brief: a centred headline with two buttons, a row of three text-only feature cards, a "how it works" row of three more, a closing call to action. FAIL if it would fit a competitor after swapping the name, if it invents customers, quotes, logos or statistics beyond the ones supplied, or if it shows a fake dashboard built from decorative charts.
