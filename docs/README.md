# Form & Force documentation

Form & Force is an open-source Agent Skill and Claude Code plugin for web work: creative direction, interface design and motion engineering. These pages explain what it does, how to install and use it, how its method works, and how to work on it.

The same pages are published as a website, built from this folder by [`site/build.py`](../site/build.py). On GitHub, read them here.

## Guides

The method in the order an agent applies it. Each guide explains a stage for people, and links to the reference the agent reads.

| Guide | Covers |
|---|---|
| [Creative direction](guides/creative-direction.md) | Reading the subject, the register, the twin, dealing a hand, turning answers into devices |
| [Visual exploration](guides/visual-exploration.md) | Sketching key frames, the sketch board, choosing by looking |
| [Design language](guides/design-language.md) | Deriving composition, typography, colour, imagery, coded visuals and a design system from the chosen frame |
| [Motion](guides/motion.md) | Whether something should move, motion character and tokens, choreography, scroll, reduced motion, the motion strip |
| [Building](guides/building.md) | Working in your stack, components and the atlas, accessibility, responsive design, performance, security |
| [Quality: the floor and the jury](guides/quality.md) | The ten hard gates, the static scan, the rendered audit, the jury and its verdicts, the report |
| [Reviewing existing work](guides/reviewing.md) | Audits and critiques that redesign nothing uninvited |
